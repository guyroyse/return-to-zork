The Stone Breaker font and the background image are licensed through Envato Elements. Coelacanth (from github.com/Fuzzypeg/Coelacanth) and Fira Code Nerd Font are SIL OFL, with their licence files kept beside them. The Font Awesome icons and favicon are CC BY 4.0.

**Why it matters:** the Envato licence allows keeping these assets in this repo, so don't suggest moving them to `.gitignore`. Any new font must allow redistribution; fonts that ship with Microsoft Office don't.
